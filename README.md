# Skills gratuitas para o Claude · Trentin Solutions

Skills em português para o Claude que resolvem problemas reais de pequenos negócios: preço e estoque, cadastro de produtos, catálogo, prospecção e avaliações do Google. Cada uma foi pensada para quem não é da área de tecnologia e explica tudo em linguagem simples.

Criadas por [Ivaldo Trentin](https://www.linkedin.com/in/ivaldotrentin/), arquiteto de soluções em Bauru, SP. Cada skill também tem página própria, com simulador e perguntas frequentes, em **[trentinsolutions.com.br](https://trentinsolutions.com.br)**.

## Como instalar

1. Baixe o .zip da skill (link na tabela acima ou na página da skill). Se preferir, compacte a pasta da skill deste repositório.
2. Na área de Skills das configurações do Claude, envie o arquivo.
3. Pergunte do seu jeito. Exemplo: *"Paguei R$ 38 numa garrafa e vendo por R$ 79,90 na Shopee. Estou tendo lucro?"*

Nenhuma skill exige assinatura paga além do próprio Claude. Cada pasta tem um `SKILL.md` (as instruções que o Claude segue), um `README.md` explicando a skill e, quando precisa, referências, exemplos e scripts em Python.
